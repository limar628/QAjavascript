# QAjavascript

Estudos de JavaScript voltados para QA (Quality Assurance). Aqui eu pratico programação aplicada a **validação de dados**, o mesmo tipo de regra que um QA testa em formulários de cadastro.

## O que estou praticando

- Percorrer listas de objetos com `for`
- Validar dados de cadastro: e-mail vazio, tamanho do nome e tamanho da senha
- Valor limite: testar senhas com 5, 6, 12 e 13 caracteres
- Funções (em andamento)

## Como executar

É preciso ter o [Node.js](https://nodejs.org) instalado. Em um terminal, dentro da pasta do projeto, rode:

```
node app.js
```

Para os arquivos que estão dentro de pastas, troque `app.js` pelo caminho do arquivo.
